## Overview

Migrating a server is like moving house. It's easy to underestimate what's in the cupboards.

## What we handle

- Physical to virtual, and on-premises to cloud
- Windows and Linux server upgrades
- Database and application server moves
- File server and email migrations
- Data centre relocations
- Backup and disaster recovery afterwards

## Steps

### Discover

What's on the old servers, and what depends on them.

### Plan

A schedule, a rollback option and a test environment.

### Cut over

At a time that suits you.

### Support

Close watching while things settle.

## FAQ

### How much downtime should we expect?

We plan for as little as possible and agree the window with you beforehand.

### What if something goes wrong?

That's what the rollback plan is for. We agree it before we start.

### Can you move us from on-premises to the cloud?

Yes, and the other way, or between data centres.

### Do you migrate email and file servers too?

Yes, along with databases and application servers.

### What happens to the old servers?

We agree how long to keep them, then retire them securely.
