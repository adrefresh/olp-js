## What we build

- **Web applications** — Internal tools, portals, dashboards and workflow systems.
- **Mobile apps** — iOS and Android, native or cross-platform.
- **APIs and integrations** — So data moves without anyone copying it.
- **Modernisation** — Updating an older application without starting from scratch.
- **Support** — Fixes, upgrades and new features after launch.

## How we work

We work in short cycles, so you see something running early and can steer. Before any code, we agree what success looks like. You get the source code and documentation.
