## Overview

Cloud is easy to start and easy to overspend on. We set it up sensibly, keep it secure and review it regularly so you aren't paying for capacity you don't use.

## What's included

- Environments set up on AWS or Azure
- Migration from servers or other hosting
- Cost monitoring and right-sizing
- Security settings and access control
- Backups and disaster recovery
- Monitoring and alerts
